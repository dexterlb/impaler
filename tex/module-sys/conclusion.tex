\section{Conclusion}
The programming language ILD, presented in this paper, is semantically
simple and easy to implement. Together with a set of host functions
and data structures, provided via FFI, and a metaprogramming library,
it lets the user write modular programs with great expressive power.
Callsite-triggered macro expansion, which we introduce, allows for
minimal language semantics and evaluator while being as powerful
as traditional macro systems. In the future we aim to improve performance
by employing partial evaluation as an optimisation step.
