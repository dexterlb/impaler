\section{Complex control flow on top of CPS}

ILD's semantics is built on CPS, similar to Scheme. This allows implementing
popular non-linear control flow constructs such as try/catch, early return
and coroutines in the language itself~\cite{r5rs}.
The following example illustrates early return from the recursive computation
enacted by \ild{map}:
\begin{ildcode}
(!fn try-map (f l)
  (call/cc (!lambda (return)
    (return (map
      (!lambda (x)
        (!if (fail? (f x))
          (return
            (make-fail
            (list 'fail-in-element x (f x))))
          (f x))) l)))))
\end{ildcode}
\lstcaption{Early return from \ild{map}}
If \ild{f} returns failure for an item in the list, the subsequent items will not
be processed.
