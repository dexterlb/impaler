\begin{abstract}
We present a minimal LISP-like language called ILD, designed for deep embedding
in a host environment, and provide a small reference host environment with
fully-immutable data. We define ILD's metaprogramming semantics based on
\emph{callsite-triggered} macro expansion, where macros are ordinary
first-class functions. We then demonstrate the expressiveness of this system by
incrementally building a library written in ILD itself that can serve as a
basis for modular user programs that employ named functions, mutual recursion
and source imports, with none of these features being built into the base
language.
\end{abstract}
