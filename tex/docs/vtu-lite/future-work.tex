\section{Future work}
\label{future-work}
ILD, as described in this paper, serves as a toy language to explore
the concept of metaprogramming with macro expansion on ordinary functions.
These ideas can be further developed into a general-purpose programming language.
\subsection{Performance}
Performing macro expansion at runtime incurs a significant performance cost.
This limitation has been studied in programming languages that use \emph{fexprs}
for runtime metaprogramming~\cite{kernel-report}. Research has demonstrated
that partial evaluation used as an optimisation pass can greatly reduce that
overhead~\cite{fexpr-pe}. Even though ILD's macro expansion is triggered at the
callsite rather than using fexprs, we believe that these ideas can be adapted
to ILD as well.
\subsection{Practical features}
ILD currently lacks the following features that would make it useful as
a general-purpose language:
\begin{itemize}
\item Side effects and IO
\item More advanced data structures, including ones that can represent cyclic relations
\item Performant interpreter or compiler
\end{itemize}
In further research we would like to build these concepts.
