\section{Example core library excerpts}
\label{ild-code-appendix}
A trimmed excerpt of \pathcode{"core/prelude.ild"}, with elided definitions
denoted as \ild{...}, is shown in \cref{ild-code-prelude}.
\begin{listingbox}\begin{ildcode}
(module
  (doc "some core functions")
  (exports lambda letrec if list)
  (imports
    (host
      (free-vars macroexpand mk-lambda ...)))
  (defs
    '(lambda ...)
    '(letrec ...)
    '(list (!lambda args args))
    '(if ...)))
\end{ildcode}\end{listingbox}
\lstcaption{Example module \code{"core/prelude.ild"}}\label{ild-code-prelude}
The helper \ild{fn}, implemented in \pathcode{"core/module-utils.ild"}, is shown in \cref{ild-code-module-utils}.
\begin{listingbox}\begin{ildcode}
(module
  (doc "some helpers for working with modules")
  (exports fn)
  (imports
    (host
      (macroexpand quote))
    ("core/prelude.ild"
      (lambda list)))
  (defs
    '(fn (!lambda (name arg-spec body)
      (list quote
        (list
          name
          (lambda arg-spec body)))))))
\end{ildcode}\end{listingbox}
\lstcaption{Example module \code{"core/module-utils.ild"}}\label{ild-code-module-utils}

The entire library, together with a working ILD interpreter,
is available in the ILD git repository~\cite{ild-repo}.
